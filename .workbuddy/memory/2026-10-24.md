# 2026-10-24

## 再次确认：开代理后 JIEYOU 同步/谱子全挂 = 腾讯云域名被代理劫走

**现象**：打开 Clash（iKuuu 订阅）后，「路演演唱次数暂未同步」「识曲记录暂时未连接」「云端暂时未连接，谱子仅保存在本机」、谱子裂图 一起出现；关掉代理即恢复。

**A/B 实测（curl）**
| 目标 | 直连 | 走 127.0.0.1:7890 |
|---|---|---|
| `jieyou-3gr01mvob9ad92de-1386199420.tcb.qcloud.la` | 418（可达，无签名正常报错） | 000，TLS 握手失败 |
| `tcb-api.tencentcloudapi.com` | 404（可达） | 000，TLS 握手失败 |
| `www.baidu.com` | — | 200（GEOIP,CN 走 DIRECT） |
| `www.google.com` | — | 000，15s 超时（节点本身也不行） |

**根因**：Clash 规则集靠 `GEOIP,CN,DIRECT` 兜底，但 `tencentcloudapi.com`（API 网关有海外边缘）与 `tcb.qcloud.la`（COS）解析不出 CN IP / 被 fake-IP 干扰，于是落到最后的代理节点。节点再一挂，TCB 的 `callFunction` + 匿名登录 + 谱子签名地址全部失败。百度能通正是因为 GEOIP 判定为 CN。

**解法（给用户）**：在 Clash 规则最前面加 DIRECT：
```yaml
- DOMAIN-SUFFIX,tencentcloudapi.com,DIRECT
- DOMAIN-SUFFIX,qcloud.la,DIRECT
- DOMAIN-SUFFIX,qcloud.com,DIRECT
- DOMAIN-SUFFIX,myqcloud.com,DIRECT
- DOMAIN-SUFFIX,tcloudbase.com,DIRECT
- DOMAIN-SUFFIX,cloudbase.net,DIRECT
```
只改 profile（配置 → 右键 → 编辑）在订阅更新后会被覆盖；要持久需用 设置 → Mixin。

**代码侧观察**：`src/services/tcb.ts` 的 `timeout: 70_000` 让代理故障时每次调用要卡很久才报错，UI 表现为长时间转圈后突然"未同步"。可考虑降到 15–20s 并单独识别网络层失败，但会影响弱网谱子上传，未擅改。

**这是第二次同类问题**（上一次是 Clash 全局模式，见 2026-10-23 记录）。排查口诀：先 A/B curl（`--noproxy '*'` vs `-x 127.0.0.1:7890`），能直连不能代理 = 路由问题，不是代码问题。

### 更正：真正原因是「全局模式」，不是 GEOIP 判错

上一节把根因归到 GEOIP/CN 判定失误，**不准确**。本轮直接读 Clash 实时 API 才看清：

- `GET http://127.0.0.1:58442/configs` → `"mode":"global"`，`proxies/GLOBAL` → `🇺🇲 美国W02 | IEPL | x1.5`
- profile 里有 **9816 条规则**（含 `🇨🇳 国内网站`、`GEOIP,CN,DIRECT`），但**全局模式会整体忽略规则**，所有流量一律从美国节点出去。
- 于是腾讯云 API / COS 也从美国落地 → TLS 握手失败（000）；github/youtube/cloudflare 反而 200。

**验证**：`PATCH /configs {"mode":"rule"}` 后立刻复测，同一批请求：
| 目标 | global | rule |
|---|---|---|
| `…tcb.qcloud.la` | 000 | **418**（可达） |
| `tcb-api.tencentcloudapi.com` | 000 | **404**（可达） |
| `cloud.tencent.com` | 200（0.9s，绕道） | 200（0.07s，直连） |
| youtube / github | 200 | 200 |

**为什么"以前一直开着代理也没事"**：开着代理 ≠ 全局模式。profile 本身写的是 `mode: Rule`，但 CFW 会用自己记住的状态覆盖它（日志 `恢复到: 12` / `恢复代理设置`），所以某次切到全局之后，**每次启动都还是全局**。变化的是模式，不是"开没开代理"。

**另一个坑**：`D:/Clash.for.Windows-0.20.16-ikuuu/data/config.yaml` 是 iKuuu 的占位配置，节点名叫「您选错了配置」「此配置无节点」「请重新导入配置」，规则只有 `MATCH,DIRECT`。误选它会出现"代理开着但完全不生效"。

**注意**：`PATCH /configs` 只改运行时，不落盘；要在 CFW 的「代理」页顶部手动选「规则」，CFW 才会记住。Clash 控制器 `secret` 为空（`127.0.0.1:58442`），本机任何进程都能改它的配置。
