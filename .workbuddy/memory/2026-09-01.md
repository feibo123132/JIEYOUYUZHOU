## 谱子压缩清晰度修复（高清版）✅

用户反馈：iPad（GitHub Pages 网站）上传的谱子很模糊，失去使用意义。原因：压缩参数（长边 1500px + JPEG 0.72）适合照片，但对文字密集谱子太小。

用户使用形态：**一首歌一张拼合长图**，页数需求极小 → 资源全部集中到单页质量。

### 改动
- `songScores.ts`：
  - `SCORE_PAGE_LIMIT` 16 → 4；`SCORE_PAGES_TOTAL_LIMIT` 2.4M → 4.6M 字符
  - `compressScoreImage` 重写：**宽度基准**（宽 >2000px 才缩，长图纵向高度不设上限）+ JPEG 0.90，超 4.4M 字符自动降级（0.85 → 宽×0.85 → 宽×0.7/0.80），硬上限 4.55M 拒绝并提示裁剪
- `SongDetailPanel.tsx`：`addScorePages` 增加总字符本地预检（避免总量超限时整条缓存被 parseSongScores 过滤）；文案标注「支持拼好的长图」
- `cloudfunctions/songRequestSync/validation.js`：
  - `SONG_SCORES_REQUEST_LIMIT` 3MB → 5MB（腾讯云 HTTP 网关安全边界）
  - `SONG_SCORE_PAGE_LIMIT` 16 → 4
  - `SONG_SCORE_PAGES_TOTAL_LIMIT` 2MB → 4_600_000 字符
