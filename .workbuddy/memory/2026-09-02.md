## 点歌台：歌曲卡片显示练习次数/匹配度 + 按匹配度排序

用户需求：歌曲卡片歌名右侧显示「练习次数」与「匹配度」两个值（紧凑展示），并按匹配值自动重排歌曲（所有歌手生效）。

### 改动
- `src/components/SongRequest/songRequest.ts`：新增纯函数 `sortCatalogByMatchScore(catalog, records)`——按歌手分组、组内按平均匹配分降序、未练习歌曲置底保持相对顺序；顺序未变时返回原引用（避免误触发同步）。
- `src/components/SongRequest/SongRequestStation.tsx`：
  - 新增 `songPracticeStats` memo（从 songRecords 聚合每首歌练习次数 + 平均匹配分，`averageMatchScore` 从 songRecords 导入）。
  - 新增 `PracticeBadges` 组件：歌名旁两个紧凑徽章（`{n}次` 白底 / `{score}匹配` 橙色），10px 字号，无记录则不渲染。
  - 新增 `handleSortByMatch`：`requireCatalogManager()` 权限校验 → 过滤 practice 记录 → `sortCatalogByMatchScore` → `commitSongOrder(sorted)` 持久化+云同步，`showSyncMessage` 反馈。
  - 工具栏「调整排序」旁新增「按匹配度排序」按钮（ArrowUpDown 图标）。
- `tests/songOrder.test.ts`：新增 2 个单测（组内降序+未练习置底不跨歌手；顺序不变返回原引用）。5/5 通过。
