# dispatching-parallel-agents

仅对独立、足够大的任务并行；不按任务数量机械拆分。
- 明确各代理职责、文件所有权和验收条件，避免修改同一状态。
- 仅使用已允许且可用的代理工具；不擅自切模型、降低质量或扩张任务范围。
- 主代理做独立工作，收集结果后检查冲突与关键行为。
- 小改动、紧密依赖步骤和低 Token 预算优先本地完成；不宣传未经测量的固定倍数节省。
