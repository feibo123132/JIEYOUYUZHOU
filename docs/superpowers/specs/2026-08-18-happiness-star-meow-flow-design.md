# 幸福星找杰宝联动设计

日期：2026-08-18

## 目标

把幸福星详情与猫猫生成器连接起来。用户从任意幸福星点击“找杰宝”后，在当前标签页进入猫猫页面；该星留言持续显示在猫猫上方，并同步成为纪念卡副标题。不同星星必须传递各自留言，不能共享、写回或覆盖星星数据。

## 星星详情弹窗

- 以下详情弹窗改动仅在 `theme.id === 'life'` 的“生命万岁企划”中启用。
- 在白色详情卡右上角增加 `×` 按钮，替代原底部“关闭”功能。
- 原底部“关闭”按钮改为“找杰宝”。
- 当前用户拥有该星星时，底部保持双按钮：“找杰宝”和“删除”。
- 当前用户不拥有该星星时，“找杰宝”占满底部宽度。
- `×` 只关闭详情弹窗，不触发导航或数据操作。
- “找杰宝”读取当前 `selectedStar.message.trim()`；空字符串或缺失留言回退为“这一刻值得被记住”。
- `jieyou` 主题继续保留原详情弹窗和底部“关闭”按钮，不出现“找杰宝”，避免改变既有流程。

## 导航与数据传递

- 采用当前标签页导航，不打开新窗口。
- 点击“找杰宝”时，把当前星星的规范化留言与 `createdAt` 组成一个 JSON 对象，通过一次 `sessionStorage.setItem` 写入同一个专用键。
- 每次点击不同星星都以单次写入原子覆盖整个对象，避免出现新留言搭配旧日期的半更新状态，确保二者始终来自同一颗星。
- 导航地址为现有猫猫生成器地址并追加来源标记，例如 `meow-generator/index.html?source=happiness-star`。
- 猫猫页只有在 `source=happiness-star` 时才读取该临时留言；普通主题入口没有来源标记，继续保留原有随机猫语行为。
- 每次点击不同星星都覆盖当前标签页的临时键，因此猫猫页显示最新被点击星星的留言。
- 不修改 `StarData.message`，不调用星星更新接口，不把留言复制到 CloudBase、Supabase 或本地 mock 数据。
- 若 `sessionStorage` 不可用、键缺失或内容为空，使用“这一刻值得被记住”。

## 猫猫气泡

- 幸福星来源模式下，气泡固定绑定猫猫，始终保持可见，并持续显示传入留言。
- 该模式不再用随机猫语替换幸福留言；猫猫、鱼和鸭的随机对白暂停。
- 气泡沿用现有猫猫锚点与屏幕边缘限制，长留言完整换行显示。
- 普通入口不受影响，仍按原时间和角色规则显示随机对白。

## 纪念卡

- 实时纪念卡中的 `MEOW GENERATOR` 改为“幸福时刻”。
- 导出 PNG 中同一位置也改为“幸福时刻”，确保预览与导出一致。
- 原“猫猫纪念卡”副标题在幸福星来源模式下改为对应星星留言。
- 短留言完整显示；长留言最多三行，超出部分以省略号结尾。
- 普通入口的纪念卡副标题继续使用原有本地化文案；“幸福时刻”作为新的统一主标题。
- 卡片左上角版标统一改为 `JIEYOU×HAPPiNESS`，实时卡与导出 PNG 保持一致；按用户指定保留小写 `i`。
- 卡片底部原仓库文字统一改为“谢谢你分享自己的幸福，愿它能一直陪伴着你😊”，实时卡与导出 PNG 保持一致。
- 幸福模式使用独立的标题排版：主标题略微上移并缩小，留言下移，在最多三行时仍须结束于编号/稀有度区域上方，不与“幸福时刻”或下方元信息重叠。
- 幸福星来源打开纪念卡时，卡片画面区域内继续显示当前幸福留言气泡；原场景气泡仍隐藏，避免在卡框外重复出现。
- 导出 PNG 时不能依赖 DOM 截图，而应在 Canvas 的卡片画面区域内绘制同样的圆角气泡、尾巴和完整换行留言，保证下载图片保留文字。
- 幸福模式左下角不再显示随机卡片编号，改为所选星星的点亮日期，格式为 `YYYY年M月D日`；普通猫猫入口继续显示原卡片编号。

## 代码边界

- `src/utils/meowGenerator.ts` 负责生成普通入口和幸福星入口 URL，并集中定义来源标记及 sessionStorage 键，避免字符串散落。
- `StarrySky.tsx` 负责以 `theme.id === 'life'` 为边界，从当前 `selectedStar` 取得留言、写入临时存储并导航；`jieyou` 主题继续使用原详情交互。
- `vendor/meow-generator/src/main.js` 负责解析来源、读取留言，并把固定留言传给气泡与纪念卡。
- `vendor/meow-generator/src/speechBubbles.js` 增加可选固定猫猫文案，不改变普通随机模式。
- `vendor/meow-generator/src/shareCard.js` 接收可选幸福留言，统一更新实时卡片和导出画布。
- 修改 vendor 源码后按现有 `UPSTREAM.md` 构建，并把生成的 `dist` 同步到 `public/meow-generator`，不直接手改压缩 bundle。

## 错误与兼容处理

- 浏览器禁止 `sessionStorage` 时不阻止导航，猫猫页显示回退文案。
- 读取到非字符串、空白或异常超长值时先规范化；最多使用现有星星留言上限 200 字。
- 查询参数仅传来源标记，不把私人留言正文暴露在 URL、日志或网络请求中。
- 点亮时间同样不进入 URL。猫猫页在幸福来源模式中读取原始 `createdAt` 并格式化为 `YYYY年M月D日`；缺失、读取异常或无效日期显示“日期未知”，不使用随机卡号冒充点亮时间。
- 猫猫生成器仍保持静态页面和同源部署，不新增后端依赖。

## 验收标准

1. `life` 主题详情弹窗右上角出现 `×`，底部不再有“关闭”。
2. 点击不同幸福星的“找杰宝”，猫猫气泡和纪念卡分别显示对应留言。
3. 幸福留言在猫猫上方持续可见，不被随机对白替换。
4. 空留言显示“这一刻值得被记住”。
5. 实时纪念卡与导出 PNG 均显示“幸福时刻”和对应留言；长留言最多三行并省略。
6. 普通猫猫入口继续使用随机对白和原纪念卡副标题。
7. 星星原始留言、坐标、所有权和云端数据没有变化。
8. 主项目测试、猫猫生成器相关测试和生产构建通过。
9. JIEYOU 主题的星星详情弹窗与既有关闭流程保持不变。
10. 幸福卡的“幸福时刻”与留言不重叠；左上角显示 `JIEYOU×HAPPiNESS`，底部显示“谢谢你分享自己的幸福，愿它能一直陪伴着你😊”。
11. 打开幸福纪念卡预览和下载 PNG 后，猫猫上方均保留对应留言气泡。
12. 幸福卡左下角显示对应星星的点亮年月日，普通入口仍显示卡片编号。
