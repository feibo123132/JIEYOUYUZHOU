# 猜歌参与者与双榜设计

## 参与流程

- 点击“参与”后显示紧凑的用户名输入框与“开始答题”按钮。
- 用户名去除首尾空格后必须为 1–24 个字符；开始答题后，本轮每条作答记录都保存该用户名。
- 退出参与、点击“下一位玩家”或切换路演时清空用户名并回到待参与状态；历史记录不受影响。

## 排名规则

- 每答对一首歌曲获得 1 分，用户成绩跨所有路演累计。
- 用户榜依次按得分、正确率、答题总数降序排列，最后按用户名稳定排序。
- 同名用户按 `trim().toLocaleLowerCase()` 合并；展示名取按 `answeredAt + id` 排序后的最早有效拼写，最终同分时按 `zh-CN`、`sensitivity: base` 的用户名顺序稳定排序。
- 用户榜展示用户名、得分、正确率、答题数与答对数。
- 歌曲榜保留现有歌曲正确率统计与排序。

## 界面

- 猜歌榜默认展示用户榜。
- 右侧增加与现有“总榜 / 随机”同风格的“用户榜 / 歌曲榜”双按钮，切换中央排名内容。
- 现有答题改判、每轮四首、等级分页与云端同步行为保持不变。

## 云端契约

- 继续使用 `roadshows:publicQuizRanking`，保留现有 `ranking` 歌曲榜字段以兼容旧客户端，并新增 `participantRanking`。
- `participantRanking` 每项包含 `participantName`、`score`、`answerCount`、`correctCount`、`accuracy`，最多返回 500 项。
