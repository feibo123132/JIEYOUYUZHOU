# 星空星星防重叠布局设计

日期：2026-08-18

## 目标

修复星空版中历史星星或不同尺寸星星在视觉上互相覆盖的问题。处理只发生在浏览器显示层，不修改 CloudBase、Supabase、本地 mock 或任何星星的持久化坐标。

## 布局规则

- 输入为当前星空版准备显示的星星、每颗星星原始百分比坐标、图标尺寸和星空容器像素尺寸。
- 使用图标半径、现有光晕范围及额外间距计算碰撞半径，目标是图标与主要光晕不明显覆盖。
- 先保留原始坐标；检测到两个圆形占位区域相交时，沿两者中心连线将双方各推开一半。
- 两颗星坐标完全相同时，用星星 ID 生成稳定方向。算法不得使用 `Math.random()`，相同输入和视口必须得到相同布局。
- 进行有限轮迭代，每轮后将星星限制在安全区域内。算法不修改输入对象。
- 稳定性以“相同可见星星集合 + 相同容器尺寸 + 相同禁入区域”为前提。现有“随机 30 颗”仍可在刷新后选出不同集合；算法不改变这一既有随机展示行为。
- 默认随机展示、完全展示、昵称/日期筛选以及新建星星都使用同一套布局。

## 安全区域

- 星星中心限制在星空容器内部，并根据自身半径保留边缘间距。
- 顶部避开标题安全带；左上避开返回键；右上避开助手入口；底部避开点亮按钮和提示区。
- `StarrySky` 根节点、标题、返回键、助手入口、版面切换箭头和底部 CTA 使用可查询的 DOM 标记。布局前读取各控件的 `getBoundingClientRect()`，转换为相对星空容器的像素禁入矩形并传给布局函数；不得只依赖固定百分比猜测控件尺寸。
- 防重叠布局只用于星星版。弹幕版、沉浸弹幕模式和弹幕轨道不参与计算。

## 响应式行为

- `StarrySky` 使用 `ResizeObserver` 读取星空容器尺寸；不可用时回退到窗口尺寸。
- 容器尺寸改变时重新计算显示坐标，不写回数据、不产生新的网络请求。
- 手机或极端密集状态下采用分级降级：先逐步缩小额外光晕间距至 0，再继续迭代保证图标主体间距。若在禁入区域之外连所有图标主体都无法数学上容纳，则保留全部星星、保持边界与禁入区域约束，并允许最小残余重叠；不得隐藏星星、缩小用户选择的图标尺寸或写回坐标。

## 组件边界

- 新增 `src/utils/starLayout.ts`，导出纯函数和必要类型，只负责布局计算。
- `StarrySky.tsx` 负责测量容器并把 `visibleStars` 转换为 `layoutStars`。
- `UserStar.tsx` 保持不变，继续接收百分比坐标。
- 详情、删除、创建、搜索、主题隔离和弹幕数据继续使用原始星星对象；仅 `UserStar` 的 `x/y` 使用显示坐标。

## 验收标准

1. 图中同坐标或相邻过近的星星会稳定错开，不再明显重叠。
2. 对相同可见星星集合，在相同窗口尺寸和控件布局下显示位置保持一致。
3. 调整窗口大小后重新排布，星星不越过安全区域。
4. 云端和本地保存的原始坐标没有改变。
5. 星空搜索、全部展示、新建、详情和删除功能保持可用。
6. 弹幕版与弹幕模式不受影响。
7. TypeScript 检查和生产构建通过。
