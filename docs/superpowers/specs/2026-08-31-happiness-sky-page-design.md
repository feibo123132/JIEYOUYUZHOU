# “幸福的模样”全屏幸福星空设计

## 目标

“幸福的模样”不再以居中弹窗出现，而是成为生命主题内的全屏子页面。页面复用 App 已挂载的 Three.js 旋转星空背景，形成与“生命万岁”一致的沉浸式空间，同时保留既有本地幸福关键词统计逻辑。

## 页面切换

- 入口仍位于助手栏“小工具”中，与“管理员模式”同级，仅生命主题显示且所有用户可用。
- 点击“查看”后，`StarrySky` 切换到全屏 `HappinessSkyPage`；不新增路由，也不重复创建 Three.js 画布。
- 全屏页隐藏原用户星星、留言弹幕、助手栏、左右切换箭头、“点亮星星”、星星详情及创建弹窗。
- 左上角只保留“返回”，返回后恢复原生命星空及入口焦点；Escape 同样返回。
- 顶部标题由“生命万岁”改为“幸福的模样”，下方显示“从 X 颗星星里，看见 Y 种幸福”。

## 关键词宇宙

- 继续读取当前完整生命星星列表，使用现有 `analyzeHappinessPortrait` 在浏览器本地提取最多 12 个幸福关键词，不调用外部服务。
- 每个关键词使用严格正圆按钮：宽高始终相等，`border-radius: 50%`，不再使用胶囊或椭圆。
- 圆圈直径与字体字号使用同一个归一化词频比例计算。高频词同时获得更大的圆圈、更大的文字与更强的光晕。
- 关键词已按频次降序排列，稳定位置表也按离画面中心的距离递增排列，因此出现次数越多，位置越靠近中心；同频时沿用词典顺序保证稳定。
- 桌面端使用 CSS `perspective`、不同 `translateZ` 深度和指针轻微倾斜产生空间感；移动端改为稳定网格，仍保留尺寸排名和光晕，避免重叠。
- 默认不展开任何留言，保持星空干净。点击关键词后，右侧浮出最多 3 条代表留言；再次点击当前词或点击面板关闭按钮收起。

## 空状态与无障碍

- 无留言时显示“这片星空正在慢慢长出幸福的模样”。
- 有留言但无关键词命中时显示“幸福还没有名字，但它已经在这里发生”。
- 页面使用 `main` 与标题关联；圆形关键词是可聚焦按钮，选择状态使用 `aria-pressed`；代表留言区域使用 `aria-live`。
- 支持 `prefers-reduced-motion`：关闭入场、漂浮、景深旋转动画。

## 验证

测试先行验证：全屏页结构、正圆尺寸变量、字体与圆圈共享词频比例、稳定位置按中心距离排序、默认不选中、点击切换、返回/Escape、StarrySky 早返回隔离，以及旧弹窗不再挂载。运行幸福功能相关测试、TypeScript 检查与 scoped diff 检查；生产构建只尝试一次，若再次遇到已知 `esbuild spawn EPERM` 则按项目规则止损。

## 标题与统计布局修订

- 删除英文眉题 `THE SHAPE OF HAPPINESS` 及其装饰星芒。
- 中文标题改为与生命星空“生命万岁”一致的白色粗体无衬线风格，字号保持同级，并在标题左右各放一枚金色星芒。
- “从 X 颗星星里，看见 Y 种幸福”从标题下方移至页面底部水平居中，位置参考生命星空的“点亮星星”区域；它仍是说明文字，不做成可点击按钮。
- 关键词区域上下边界同步收紧，给顶部标题和底部统计留出独立安全区。
