# 听歌识曲歌库设计

## 目标

在点歌台四宫格下方增加横跨两列的“识曲歌库”总部；管理员可在歌手歌曲列表中把歌曲采购进四个难度档次，并在总部按档次集中查看和调整。

## 交互

- 总部入口保持现有四宫格不变，新增一张较矮的横向卡片，展示总歌曲数与四档数量。
- 四档为 `简单`、`常规`、`较难`、`很难`，分别使用绿、蓝、紫、红色识别。
- 歌手歌曲行在 `🔥` 左侧增加唱片形分级按钮；管理员点击后弹出四档菜单，选择后立即归档，再选当前档取消入库。
- 普通访客只看到已分级歌曲的彩色等级徽标，不显示编辑菜单。
- 总部按四档展示歌曲，空档位显示引导文案；调整或移除档位统一在歌手页完成。

## 数据与同步

识曲歌库保存为 `songId -> level` 映射。读取公开，写入沿用热门歌曲管理员身份校验与 CloudBase 云同步；云端不可用时保持当前界面状态并提示失败。

## 验证

- 纯函数测试覆盖数据校验、分档、计数与切换/取消。
- 源码契约测试覆盖总部入口、四档文案、分级按钮位于热门按钮之前。
- 云函数测试覆盖公开读取、管理员写入、去重与非法等级拒绝。
- 运行定向测试、TypeScript 检查和生产构建。
