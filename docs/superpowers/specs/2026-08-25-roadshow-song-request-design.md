# 吉他路演点歌台设计

## 目标

用首页右下角的“点歌台”替代已移除的“留影”入口。功能服务于吉他路演现场共用的一台设备：观众浏览表演者会唱的歌曲、搜索并点歌；每次点歌长期累计，形成“点歌榜”。不提供歌曲播放能力。

## 交互与信息结构

- 首页卡片沿用现有四宫格尺寸，使用暖红、琥珀色舞台灯光视觉，标题为“点歌台”。
- 点歌页桌面端采用“曲库 + 点歌榜”双栏，移动端纵向排列。
- 顶部提供返回、页面标题、搜索框和分类筛选。
- “热门歌曲”由歌曲配置中的 `featured` 标记决定，只作为推荐集合，不显示名次。
- 完整曲库展示歌名、歌手、分类和“点歌”按钮；搜索匹配歌名或歌手。
- 点击后累计一次并给出短暂成功反馈，不播放音频、不建立播放队列。
- “点歌榜”按累计次数降序展示；同票时保持歌曲配置顺序。

## 数据与维护

- 歌曲清单集中放在独立 TypeScript 配置文件，字段包含稳定 `id`、歌名、歌手、分类和是否热门，便于后续直接编辑。
- 点歌次数保存在当前浏览器 `localStorage`，刷新和重启后保留；无需网络、账号或后端。
- 读取到无效或旧数据时忽略异常条目并回退为空统计，页面继续可用。
- 首版不提供清空统计按钮，避免现场误操作；不做云同步、登录、播放和版权内容接入。

## 测试

- 纯函数覆盖搜索、分类、累计计数、点歌榜排序和异常持久化数据恢复。
- 源码契约覆盖首页点歌入口和应用视图导航。
- 最后运行定向测试与生产构建。
