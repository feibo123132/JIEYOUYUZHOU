# 歌曲详情与练习/路演记录设计

## 目标

让曲库中的每首歌曲都能进入独立详情视图，供本人长期记录多次吉他弹唱练习和现场路演反馈。记录属于私有数据，沿用现有点歌台私有空间，并通过腾讯云开发在电脑和手机之间同步。

## 交互设计

- 点击歌曲卡片主体进入详情；卡片上的“点歌”按钮继续只提交点歌，不能触发详情跳转。
- 详情页顶部展示歌名、歌手、现有歌曲文案、练习次数与所有练习记录的平均匹配度，并提供返回当前歌手歌曲列表的按钮；平均值最多保留 1 位小数。顶部信息卡恢复内容区全宽，左侧眉题与右侧统计卡顶边对齐。
- 顶部信息卡提供带吉他与对话图标的“练习/路演”切换器；同步状态与左侧 `MY SONG JOURNAL · 歌手` 位于同一行，文字和云朵图标均使用 10px。页面主体左侧只展示当前类型的填写区，右侧只展示当前类型的历史数据；手机端上下排列。
- 练习记录表单包含：可选择任意日期与时刻的“练习时间”、匹配度（70–100）、练习感受、弹唱感想；不记录练习分钟数或累计时长。旧记录中的问题描述与改进办法在展示时合并为弹唱感想。
- 路演记录表单包含：可选择任意日期与时刻的“路演时间”、观众称呼（可选）、现场反馈与自己的观察。
- 两类记录均允许重复新增和删除，按发生时间倒序展示；本期不加入图表、附件和编辑功能。

## 数据与同步

- 前端新增独立的歌曲记录数据模块，按 `songId` 归属记录，使用稳定 ID 和 ISO 时间。
- 本地缓存用于首次渲染和云端不可用时的临时保底。
- 云端复用 `song_request_workspaces` 的别称与管理口令做认证，但歌曲记录单独存入 `song_request_song_records` 集合，每条记录使用“工作区 ID + 记录 ID”作为文档键，避免整份工作区读改写覆盖其他设备或原有路演数据。
- `song_request_song_records` 只允许部署后的 `songRequestSync` 云函数通过服务端 SDK 访问；部署文档要求为该集合配置“客户端禁止读写”的安全规则，客户端不能绕过别称与管理口令直接查询。
- 每条记录同时保存 `songId`、歌名和歌手快照。另一台设备遇到本地不存在的自定义歌曲时，用快照恢复一张私有自定义歌曲卡片，保证同步记录仍可进入。
- 云端是同步后的事实来源；新增记录按独立文档写入，删除在同一文档写入 `deletedAt`，拉取时过滤软删除数据，避免多设备同步后记录复活。
- 详情页只从现有 `sessionStorage` 私有会话读取别称与管理口令；没有会话时不读取或展示任何缓存，只显示“请先进入路演档案解锁”。缓存键包含规范化后的别称，锁定时清除该别称的歌曲记录缓存。
- 路演档案和歌曲记录共用认证，但数据字段与存储彼此独立。

## 组件边界

- `SongRequestStation`：管理当前选中歌曲，并保证点歌按钮与详情点击互不干扰。
- `SongDetailPanel`：只负责详情页展示、表单交互和记录列表。
- 歌曲记录数据模块：类型、校验、本地缓存、排序和增删操作。
- CloudBase 适配器/云函数：拉取、保存和软删除私有歌曲记录。

## 错误处理

- 表单校验：匹配度必须为 70–100；练习感受、问题描述、改进办法至少填写一项；路演反馈/观察不能为空；观众称呼可留空。
- 云端未认证时，引导用户先进入一次“路演”私有空间完成验证。
- 云端拉取失败时可展示当前别称的本地缓存并标明“尚未同步”；新增或删除失败时保留表单/原记录并显示短提示，不伪装成已同步。
- 无效缓存或云端记录直接忽略，避免破坏详情页。

## 验证

- 单元测试覆盖字段校验、同一歌曲多次记录、倒序展示、缓存解析与删除。
- 云函数测试覆盖私有认证、拉取、独立文档保存、软删除、并发写入互不覆盖和数据隔离。
- 缓存测试覆盖按别称隔离、未认证不读取、锁定清理及自定义歌曲快照恢复。
- 组件/适配器测试分别模拟拉取、新增和删除失败，验证缓存或表单内容不会丢失、删除失败不会移除原记录，并出现“尚未同步”提示。
- 兼容旧云端与本地缓存记录：前端解析及云函数保存校验均允许历史 `durationMinutes` 存在但直接丢弃，不再展示、校验或参与统计；后续保存不再发送该字段。测试覆盖旧云端载荷和旧本地缓存的兼容读取。
- 组件静态测试覆盖歌曲卡片可进入详情、点歌按钮阻止冒泡、两类表单字段和返回行为。
- 运行点歌台测试、云函数测试和 TypeScript 检查。
