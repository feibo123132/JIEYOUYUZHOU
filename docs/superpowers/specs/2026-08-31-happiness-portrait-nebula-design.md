# “幸福的模样”幸福星云设计

## 目标

在“生命万岁企划”的助手栏“小工具”内，于“管理员模式”下方增加同级入口“幸福的模样”。它读取当前已加载的全部生命主题星星留言（包含内置幸福星星与真实用户星星），在本地提取共同的幸福关键词，并以符合星空气质的“幸福星云”展示。

## 入口与交互

- 入口仅在生命主题显示，面向所有用户开放，不受管理员模式开关影响；它只是在布局上与“管理员模式”同级并位于其下方。右侧按钮为“查看”。
- 点击“查看”打开居中的半透明星云浮层，不跳转页面、不改动星星和留言数据。
- 浮层顶部显示“从 X 颗星星里，看见 Y 种幸福”；X 为有非空留言的星星数，Y 为命中的关键词数。
- 中部展示 `min(12, 命中关键词数)` 个关键词；命中 1–7 种时全部展示，不用零频词补齐。词频越高，文字越大、光晕越亮；位置由稳定规则决定，避免每次打开跳动。
- 默认选中最高频关键词；点击任一关键词后，下方展示包含该关键词的星星中按 `created_at` 降序、ID 升序选出的最多 3 条代表留言，并显示该词命中了多少颗星星。当前星星数据契约要求 ID 与创建时间必填；为兼容异常历史数据，无效日期排在有效日期之后，随后仍以 ID 升序保证稳定。
- 点击遮罩、关闭按钮或按 Escape 关闭浮层。

## 关键词提取

新增纯函数模块维护以下幸福词典：

- 陪伴：陪伴、陪着、一起、相伴、拥抱、接住
- 家人：家人、爸爸、妈妈、父母、爷爷、奶奶、外公、外婆、家里、回家
- 朋友：朋友、友情、同学、伙伴、闺蜜、兄弟
- 宠物：宠物、小猫、猫咪、小狗、狗狗、毛孩子
- 美食：早餐、面、饭、菜、水果、糖果、甜品、咖啡、热茶、奶茶、好吃
- 音乐：音乐、歌曲、唱歌、耳机、演出、琴
- 自然：阳光、晚霞、天空、花草、泥土、风、雨、月光、云朵、星星
- 休息：休息、睡觉、自然醒、被窝、放松、躺下、松口气、发呆
- 成长：完成、坚持、学会、进步、勇敢、努力、做到了、成长
- 被惦记：惦念、想念、回复、问候、关心、收到消息、记得我
- 仪式感：纪念、庆祝、礼物、生日、节日、记录、收藏、仪式
- 自由：自由、自在、随心、散步、出发、旅行、独处

匹配前对留言与词条执行 Unicode NFKC 规范化、转小写并移除空白与标点，然后使用子串匹配。一个词条只归属一个关键词；一颗星星的数据模型只有一条留言，该留言可以命中多个关键词，但同一关键词无论命中多少同义词都只为这颗星计数一次。结果按命中星星数降序、词典顺序稳定排序。

提取完全在浏览器本地完成，不调用 AI、云函数或第三方分词服务，不产生费用，也不上传留言。浮层直接消费当前星星列表并通过派生计算生成结果；浮层打开期间新增或删除真实星星时立即重新统计，无需关闭重开。若当前选中关键词在刷新后降为零并从结果中消失，则自动选中新结果的最高频词；若已无任何命中项，则清空选择并进入无关键词空状态。

## 视觉

浮层沿用生命主题的黑金配色：深黑半透明底、琥珀与暖橙光晕、少量玫瑰色点缀。关键词使用圆形/椭圆星体按钮而非传统矩形词云；背景只使用轻量 CSS 光点和连线，不新增图表依赖。代表留言以三张低对比度玻璃卡片呈现，保证阅读优先。

## 空状态与边界

- 无留言时显示“这片星空正在慢慢长出幸福的模样”。
- 有留言但无词典命中时显示“幸福还没有名字，但它已经在这里发生”。
- 仅分析非空留言；不改变搜索、星星显示、弹幕、管理员权限和每日点亮规则。
- 在移动端浮层改为可滚动单列，关键词星体缩小；浮层使用 `role="dialog"`/`aria-modal`，关闭按钮获得初始焦点，Escape 可关闭，关闭后焦点回到“查看”入口，并支持 `prefers-reduced-motion`。

## 验证

使用测试先行验证同义词归一、每条留言去重计数、稳定排序、最多 12 个且不足 12 个时展示全部命中项、代表留言选择、空状态、主题入口隔离、助手栏回调和浮层挂载。随后运行相关测试、TypeScript 检查与生产构建；若 Vite 再次遇到已知 `esbuild spawn EPERM`，按项目规则不重复尝试。
