# 猫咪预设保存设计

## 目标

在“场景与渲染”和“Motion”之间加入“预设保存”折叠栏，让用户命名、保存并复用当前猫咪外观。

## 范围

- 保存猫咪本身，采用显式白名单：用于精确复现程序化外观的种子、姿势、体型、毛发、线条、花纹、眼睛与颜色字段。“随机猫窝”依赖场景容器，保存时规范为站立姿势。
- 不保存场景、天气、玩具、垫子、相机和 Motion 参数。
- 使用浏览器 `localStorage`，无需账号、后端或新依赖。

## 交互

- 折叠栏默认收起，位置紧邻 Motion 之前；移动端继续复用现有的自动分类导航。
- 用户输入名称后点击“保存当前猫咪”；名称为空时显示就地提示。
- 同名预设直接覆盖；最多保存 20 个，超过时移除最旧项。
- 每个预设提供“应用”和“删除”。应用后同步控件并重建小猫。
- 存储不可用或数据损坏时保持页面可用，并显示简短提示。

### 可编辑预设

- 预设名称在列表中直接以输入框呈现；按 Enter 或离开输入框时保存改名。
- 空名称或与其他预设重名时拒绝改名，并恢复原名称。
- “应用”后，用户继续使用原有体型、花纹、眼睛等面板调整猫咪；点击该条目的“更新”即可用当前猫咪参数覆盖原预设。
- 更新保留预设名称，不引入新的参数编辑器或数据格式，因此已有预设无需迁移。

### 表情与光照

- 新保存或更新的预设额外记录当前表情，以及光照球的方位角和仰角。
- 应用预设时同步恢复表情选择框、光源方向和光照球位置。
- 旧预设缺少这些可选字段时，保留当前表情和光照，保持向后兼容。
- 不保存天气、地板或其他场景状态。

## 结构与验证

- 新增纯逻辑模块负责字段白名单、序列化、校验、覆盖和上限策略，便于 Node 单元测试。
- `main.js` 只负责 DOM、`localStorage` 适配、同步参数与触发重建。
- `style.css` 增加少量预设表单/列表样式；`i18n.js` 增加中英日文案。
- 测试覆盖字段过滤、同名覆盖、20 项上限和损坏数据回退；随后运行生成器构建。
