# 点歌台分层导航与私有路演云同步设计

## 目标

将拥挤的点歌台改为两层结构。首页只展示“点歌榜、歌手、路演、歌单”四个方向，点击后才显示详情。点歌数据跨设备共享；路演档案仅本人可查看和编辑，并支持电脑、手机同步。

## 页面结构

- 点歌台首页：标题、简短引导和四张方向卡，不出现歌曲列表。
- 点歌榜：累计点歌排行。
- 歌手：按歌手聚合，进入歌手后查看其歌曲。
- 歌单：热门歌曲与全部歌曲。
- 路演：先验证“别称 + 管理口令”，再显示路演列表与编辑器。
- 详情页返回按钮先回点歌台首页；首页返回按钮回宇宙首页。

## 路演档案

- 可创建、修改和软删除路演，字段包含名称与日期。
- 每场有两份独立清单：“路演歌曲”表示准备演唱的歌曲；“听歌识曲”表示互动游戏题目歌曲。
- 两份清单都可从现有曲库选择，也可手动输入曲库外的歌名和歌手。
- 添加歌曲时提示它曾在哪些路演出现过，帮助避免重复。

## 云同步与权限

- 复用现有腾讯云开发 SDK、匿名登录和环境变量。
- 点歌次数是公共云数据，云函数负责累计，所有设备读取同一份结果；断网时保留本地乐观计数。
- 路演档案通过云函数访问。首次使用以别称注册管理口令；服务端只保存随机盐与密码派生值，不保存明文。
- 后续每次私有请求由云函数校验别称和口令；口令仅保存在当前标签页会话中。“锁定路演”立即清除会话凭据。
- 数据库集合禁止网页直接读写，只允许云函数访问；删除使用 `deletedAt` 防止旧设备恢复已删数据。

## 验证

- 测试目录导航、歌手聚合、重复检测和本地回退。
- 测试云函数输入校验、密码验证、公共计数、私有读取、保存与软删除。
- 运行定向测试、全量测试和 TypeScript 检查；部署后才可声称真实跨设备同步可用。
