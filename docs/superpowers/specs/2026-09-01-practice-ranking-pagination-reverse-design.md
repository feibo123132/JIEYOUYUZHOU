# 吉他练习榜分页与倒序设计

## 目标

吉他练习榜每页最多展示 50 首歌，并支持将现有名次整体倒序展示，避免歌曲增多后无限向下撑长页面。

## 交互

- 默认保持现有正序榜单，每页 50 首。
- 榜单右上方增加一个紧凑的双态按钮：`正序` / `倒序`。
- 倒序只反转展示顺序，保留每首歌的真实原始名次，不重新编号。
- 榜单底部显示 `共 N 首 · 上一页 · X / Y · 下一页`，仅超过 50 首时显示。
- 切换正倒序、总榜/指定歌手时自动回到第 1 页。
- 数据减少导致当前页越界时，自动收缩到最后一个有效页码。
- `随机` 与 `倒序` 互斥：点击正倒序按钮时反转当前正倒序状态、关闭随机并回到第 1 页；开启随机时恢复正序、生成随机序列并回到第 1 页；关闭随机时回到正序第 1 页。随机序列在翻页期间保持稳定。
- 真实名次同时决定数字和奖牌样式；倒序或分页后，页首的低名次歌曲不得获得金银铜样式。
- 第一页的“上一页”和最后一页的“下一页”禁用，两个按钮均提供明确的无障碍名称。

## 数据流

1. 先按总榜或指定歌手筛选原始榜单。
2. 为筛选结果记录真实名次。
3. 根据正序、倒序或随机模式生成展示序列；名次及奖牌样式始终使用第 2 步保留的真实名次。
4. 最后对展示序列按 50 首分页，避免分页破坏全局顺序。

## 验证

- 源码定向测试覆盖 49/50/51 首边界、真实名次与奖牌样式、正倒序切换、与随机互斥及页码重置。
- TypeScript 检查必须通过。
