# 星星详情弹窗统一设计

## 目标

让 JIEYOU 主题的星星详情与幸福主题使用同一交互结构：右上角关闭按钮，以及底部“找杰宝”“我的”按钮。

## 行为与边界

- 移除仅幸福主题可见的条件分支，两个主题始终显示右上角 `X`。
- 两个主题始终显示“找杰宝”和“我的”；“找杰宝”携带当前星星的留言、时间和昵称进入现有杰宝页面。
- “我的”继续打开已有的当前主题用户留言页。
- 主按钮继续使用当前主题的渐变配色，JIEYOU 为紫色，幸福主题为橙红色。
- 原有删除按钮及权限逻辑不变；不新增组件、路由或数据请求。

## 验证

- 更新现有幸福星接入测试，使其验证弹窗操作不再受主题条件限制。
- 运行相关定向测试与生产构建。
