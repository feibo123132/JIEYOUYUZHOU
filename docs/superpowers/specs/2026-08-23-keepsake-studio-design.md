# 留影工坊设计

## 目标

在企划选择首页新增与现有功能同级的“留影”入口。用户可上传一张本地照片，填写少量文案，切换固定外框并导出高清 PNG。首版追求轻量、快速、无后端和易于继续增加外框。

## 范围

- 上传一张 JPG、PNG 或 WebP 图片，仅在浏览器内处理。
- 照片自动铺满取景窗，支持鼠标或单指拖动、滑杆缩放。
- 可编辑标题、正文、日期和署名；日期默认为当天并使用日期控件。
- 提供 3 套固定外框；外框以数据配置扩展，不提供自由拖拽装饰。
- 实时预览并导出 `1200 × 1600` PNG。
- 支持返回首页、重新选择照片，并为失败的图片读取或导出显示提示。

不包含账号同步、云端存储、滤镜、裁剪历史、贴纸、任意字体或类似 Canva 的自由排版。

## 交互与视觉

首页新增独立的“留影 / MEMORY STUDIO”卡片，视觉延续现有深色星空与暖金色强调。进入后，桌面端为预览区与控制区并排，移动端为预览在上、控制区在下。

预览采用与猫猫收藏卡一致的 3:4 纪念卡语言，但内容独立：中间为照片取景窗，下方为标题与正文，角落放置日期和署名。三套外框分别偏暖橙纸张、深蓝星图和奶油拼贴风。

## 技术设计

- 将应用视图增加 `keepsake-studio`，并增加独立的 `enterKeepsakeStudio` 动作。`ThemeHub` 通过单独的 `onOpenKeepsake` 回调进入；该页面不依赖或修改 `ThemeId`、当前主题、昵称及星星数据，返回时始终回到 `theme-hub` 并释放图片对象 URL。
- 新建留影页面和无副作用的布局/文案辅助函数。
- 使用原生 Canvas 2D 合成照片、外框与文字；不引入 Fabric.js 或完整图片编辑器。
- 统一以 `1200 × 1600` 为逻辑坐标，照片窗口固定为 `(90, 185, 1020, 980)`。预览 Canvas 只通过 CSS 等比缩放；预览和导出调用同一个渲染函数。
- 图片初始缩放使用 `max(窗口宽/图片宽, 窗口高/图片高)`，用户缩放范围为初始值的 `1–3` 倍。拖动偏移必须夹紧，保证照片始终覆盖窗口；指针位移按预览与逻辑画布的比例换算。
- 使用对象 URL 异步读取本地图片；每次读取带递增请求标识，过期结果不得覆盖新图片。替换图片或组件卸载时释放对象 URL。
- 导出优先使用 `canvas.toBlob()` 与临时下载链接。

外框配置使用稳定 ID，结构为 `{ id, name, palette, typography, decorations }`。首版三套外框共享固定照片窗口；装饰只使用 Canvas 图元和 CSS/Canvas 可用字体，不加载远程资源。每套外框可独立配置颜色、文字位置与装饰图元。

文字规则固定如下：标题默认“今日留影”，最多 18 个字符、最多一行；正文默认空，最多 80 个字符、最多三行；署名默认空，最多 16 个字符、最多一行；保留用户换行，超出宽度自动换行，超过行数以省略号结尾。字体回退为 `"Noto Serif SC", "Songti SC", "Microsoft YaHei", serif`。

## 验证

- 单元测试覆盖新视图切换、外框配置、文本截断和缩放边界。
- 运行相关定向测试与生产构建。
- 导出测试确认 MIME 为 `image/png` 且尺寸严格为 `1200 × 1600`。
- 覆盖横图、竖图、过期异步图片读取、对象 URL 释放，以及照片和文字不写入任何持久化存储或网络服务。
- 手工确认桌面端、窄屏布局、移动端拖动/缩放以及三套外框的 PNG 输出。
