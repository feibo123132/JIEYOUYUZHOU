# 弹幕亲密模式设计

日期：2026-08-18

## 目标

在助手栏的“弹幕”折叠项内增加“亲密模式”开关。开启后仅提高弹幕排列密度：相邻弹幕的横向边缘空隙和纵向轨道中心距均为普通模式的 50%，弹幕文字、胶囊尺寸和舞台范围保持不变。

## 交互与状态

- “亲密模式”与现有“弹幕模式”并列显示在“弹幕”折叠内容中。
- 两个开关彼此独立：“弹幕模式”继续控制沉浸显示，“亲密模式”只控制弹幕间距。
- 亲密模式在普通弹幕版和沉浸弹幕模式中都生效。
- 开关初始为关闭。状态保存在当前 `StarrySky` 组件会话中，不写入本地存储或云端；与现有弹幕模式一致，切换主题时恢复关闭。

## 布局规则

- 普通模式保留桌面 8 条、移动端 6 条轨道；轨道中心距分别为舞台可用高度的 `1/8` 和 `1/6`。
- 亲密模式使用桌面 16 条、移动端 12 条轨道；轨道中心距分别变为舞台可用高度的 `1/16` 和 `1/12`，恰为各端普通模式的 50%。这是本功能对“纵向距离”的度量定义。
- 同一轨道中相邻弹幕的横向边缘空隙由普通模式的 `clamp(5rem, 12vw, 14rem)` 改为 `clamp(2.5rem, 6vw, 7rem)`，在最小值、流动值和最大值区间均为 50%。
- 减少动态效果时使用静态列表；亲密模式同样将列表条目之间的纵向 `gap` 减半。
- 不缩小弹幕、不压缩舞台范围，也不改变现有动画时长公式。轨道重新分组可能使各轨道沿用现有公式得到不同的具体时长，本功能不额外调整或承诺恒定像素速度。

## 组件边界

- `StarrySky.tsx` 持有 `intimateMode` 本地状态，并负责主题切换时复位。
- `AssistantSidebar.tsx` 接收状态和切换回调，只负责渲染开关。
- `MessageBarrage.tsx` 接收 `intimate` 属性，选择普通或亲密轨道数量，并输出对应修饰类。
- `index.css` 通过 CSS 变量和修饰类控制横向间距及静态列表间距。

## 验证

1. 亲密模式关闭时保持现有 8/6 轨和 `clamp(5rem, 12vw, 14rem)` 横向间距。
2. 亲密模式开启时变为 16/12 轨，纵向轨道中心距为普通模式的一半。
3. 亲密模式横向间距为 `clamp(2.5rem, 6vw, 7rem)`；最小、流动、最大三个区间均为普通模式的一半。
4. 两种模式下弹幕大小、动画时长公式和舞台边界不变。
5. 亲密模式可独立于弹幕模式切换，并在普通/沉浸弹幕版中生效。
6. 减少动态效果下的静态列表间距同步减半。
7. TypeScript 检查、定向测试和生产构建通过。
