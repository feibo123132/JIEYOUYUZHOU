# 留影底部句子“不选”设计

## 目标

在留影编辑器的“底部句子”下拉框中增加“不选”。用户选择后，编辑预览和导出的高清 PNG 都不绘制底部句子；标题、正文、日期、地点和外框保持不变。

## 方案

- 沿用现有 `KeepsakeSentence` 中的 `'不选'` 哨兵值，不引入可空状态或新的持久化结构。
- 在“底部句子”下拉框中显式加入 `<option value="不选">不选</option>`。
- 画布渲染时仅在 `sentence !== '不选'` 时调用底部句子的 `fillText`。
- 保留当前默认行为：首次进入页面仍从三条现有句子中随机选择，不默认选择“不选”。

## 测试

- 组件源码测试确认下拉框存在“不选”选项。
- 画布单元测试确认选择“不选”时不会在底部坐标绘制任何句子。
- 现有句子绘制测试继续通过，保证普通选项行为不变。
