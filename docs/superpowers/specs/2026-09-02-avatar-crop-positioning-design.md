# 歌手头像裁切定位修复设计

## 目标

头像缩放为 1 时，仍可利用原图超出正方形头像框的部分进行上下或左右移动；旋转为 0 时的位置调整不露出空白，不改变现有头像、同步载荷或 `x/y/scale/rotation` 数据格式。旋转继续维持现有表现，本次不扩展为旋转感知的防露白算法。

## 方案

新增纯函数，根据图片自然宽高、缩放值和 `x/y` 计算封面裁切尺寸与偏移：竖图以宽度填满，允许上下移动；横图以高度填满，允许左右移动；缩放后按新增溢出量扩展两轴移动范围。`x/y` 的 0–100 分别映射到可移动范围的起点和终点。

新增共用头像渲染组件，在图片加载后读取自然宽高并应用上述布局；`src` 改变时立即清除旧尺寸，加载失败或尺寸不可用时回退到当前 `object-cover`。歌手卡片和头像调整预览统一使用该组件，旋转保留在图片层，外层继续负责圆形裁切。

## 验证

- 竖图、缩放 1：精确验证 `y=0/50/100` 对应顶部、居中、底部偏移且不露白。
- 横图、缩放 1：精确验证 `x=0/50/100` 对应左侧、居中、右侧偏移且不露白。
- 正方形、缩放 1：无多余空间，两轴保持不动。
- 缩放大于 1：两轴均可移动。
- 极端宽高比与 `x/y` 端点仍产生有限数值。
- 更换图片后重新读取自然宽高，卡片和预览使用同一布局计算结果。
- 首次加载与加载失败使用安全回退，不复用上一张图片尺寸。
- 现有歌手头像测试和 TypeScript 检查通过。
