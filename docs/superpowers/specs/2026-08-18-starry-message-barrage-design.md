# 星空留言弹幕版设计

日期：2026-08-18

## 目标

在现有主题星空页内增加第二种浏览版面，让用户无需逐颗点击星星，也能直接阅读当前主题中的留言。新功能只改变展示方式，复用已经加载的星星数据，不增加后端集合或接口。

## 页面切换

- 星空版右侧垂直居中增加圆形“→”按钮，点击进入弹幕版。
- 弹幕版左侧垂直居中增加圆形“←”按钮，点击回到星空版。
- 切换仅发生在 `StarrySky` 组件内部，不改变应用路由、当前主题、用户身份或已加载数据。
- 标题、左上角返回键、右侧小工具入口、星空背景、加载/错误状态、底部点亮按钮和创建弹窗在两个版面中保持一致。

## 弹幕内容

- 只展示当前主题中 `message` 去除首尾空格后非空的记录。
- 每条主文本为留言正文，末尾以较小、较淡的文字显示“昵称 · 日期”。
- 日期使用本地中文年月日格式，不显示具体时间。
- 昵称与日期搜索沿用现有侧栏状态；搜索生效时，弹幕版只展示匹配记录。
- 弹幕不受星空版“随机 30 颗/全部展示”开关限制，避免遗漏符合条件的留言。
- 没有可展示留言时，在中央显示空状态提示。

## 动画与布局

- 使用 DOM + CSS 分轨动画，不使用 Canvas。
- 根据可视高度设置固定数量的水平轨道；留言按稳定顺序分配轨道、速度和启动延迟，避免每次 React 渲染都跳位。
- 轨道区域从标题安全带下方开始，利用标题与原第一排弹幕之间的空白，但任何轨道都不得穿过顶部标题。
- 弹幕从视口右侧外进入，从左侧外离开并循环播放。
- 每条弹幕使用半透明深色胶囊、细边框与轻微发光，保持星空背景可见。
- 鼠标或键盘聚焦某条弹幕时暂停该条动画，便于阅读。
- 遵循 `prefers-reduced-motion`：减少动态偏好下取消横向动画，改为可滚动的静态留言列表。
- 右/左切换按钮避开顶部标题、底部 CTA 和侧栏触发区，并提供 `aria-label`。

## 助手栏弹幕模式

- 助手栏新增与“检索”“星星展示”“小工具”同级的 `💬 弹幕` 折叠项。
- 折叠内容包含“弹幕模式”开关；开关状态只保存在当前 `StarrySky` 会话，不写入云端或本地持久化。
- 开启开关时自动切换到留言弹幕版、关闭助手栏并清除已打开的星星详情。
- 弹幕模式开启且数据加载完成时，隐藏顶部标题、左上角返回、底部点亮按钮与提示、左右版面切换按钮及其他页面文字。
- 星空背景、留言弹幕和右上角助手图标始终保留。助手栏被打开时，其内部文字正常显示，用户可通过同一开关退出弹幕模式。
- 关闭开关后仍停留在留言弹幕版，恢复标题、返回、点亮按钮、提示和左侧返回星星版箭头。
- 沉浸状态下弹幕区域向下扩展，使用原底部 CTA 的空间；顶部仍遵守标题安全带，即使标题已隐藏也不让轨道紧贴浏览器边缘。
- 加载中或错误状态不允许进入沉浸模式，必要的状态说明不得被隐藏。

## 组件边界

- 新增 `MessageBarrage.tsx`：接收已筛选的留言星星和主题配置，负责轨道计算、弹幕渲染及空状态。
- `StarrySky.tsx` 新增本地 `skyView: 'stars' | 'messages'` 状态，负责两个版面的显示与箭头切换。
- `StarrySky.tsx` 新增本地 `barrageMode` 状态，并向 `AssistantSidebar` 传递状态与切换回调。
- `AssistantSidebar.tsx` 只负责展示弹幕模式开关；具体版面切换和页面显隐仍由 `StarrySky` 控制。
- `index.css` 增加弹幕横移动画、暂停态和减少动态规则。
- 数据服务、创建/删除星星、配额和主题隔离逻辑保持不变。

## 验收标准

1. 星空版右侧可进入弹幕版，弹幕版左侧可返回星空版。
2. 两个主题分别只显示各自的留言，数据不混用。
3. 留言从右向左分轨循环，末尾显示小号昵称和日期。
4. 搜索昵称或日期后，弹幕内容同步过滤。
5. 空留言不会显示；无留言时出现空状态。
6. 标题、返回、小工具、背景和点亮按钮在切换后保持可用。
7. TypeScript 检查和生产构建通过。
8. 助手栏可以开启弹幕模式；开启后除弹幕外的页面文字消失，右上角助手图标仍可用于退出。
9. 弹幕轨道利用标题下方空白且不经过标题区域；沉浸模式同时利用底部空间。
